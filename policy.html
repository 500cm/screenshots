Политика конфиденциальности расширения «Скриншоты»

Расширение «Скриншоты» предназначено для создания снимков видимой области вкладки Chrome или всей веб-страницы, с последующим сохранением в PNG либо копированием в буфер обмена.

Какие данные обрабатываются

Когда пользователь запускает создание снимка, расширение получает доступ к изображению текущей веб-страницы. Такой снимок может содержать текст, изображения и другие данные, отображаемые на странице. Для создания снимка всей страницы расширение временно прокручивает её и объединяет части изображения.

Где происходит обработка

Обработка снимков осуществляется локально в браузере пользователя. Расширение не отправляет снимки или содержимое страниц разработчику либо на сторонние серверы.

Сохранение и использование

По выбору пользователя готовый снимок сохраняется как PNG на устройстве или копируется в буфер обмена. Локальное хранилище браузера может использоваться для настроек и технического состояния операции. Расширение не использует данные для рекламы, аналитики, профилирования или продажи третьим лицам.

Управление данными

Пользователь самостоятельно управляет сохранёнными файлами и содержимым буфера обмена. Данные и настройки расширения можно удалить средствами Chrome.

Контактная информация

По вопросам конфиденциальности обращайтесь через контактную информацию разработчика на странице расширения в Chrome Web Store.

Политика распространяется на расширение «Скриншоты» версии 1.0.3.
